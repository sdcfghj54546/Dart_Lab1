## Ответы на вопросы

**1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?**
В Dart тип переменной известен на этапе компиляции, а в Python — во время выполнения (динамическая типизация). Главное практическое преимущество Dart в том, что огромное количество ошибок (например, передача строки туда, где ожидается число) отлавливается компилятором еще до запуска программы. В Python такие ошибки приведут к падению программы (Runtime Error) прямо во время работы.

**2. Что означает String?? Чем отличается от String?**
`String?` — это nullable-тип, который может принимать значение null. Обычный `String` не может быть null. Разница в том, что для String? компилятор обязывает делать проверку на null перед использованием, что предотвращает ошибки в рантайме.

**3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?**
Ключевое слово `final` перекладывает контроль с программиста на компилятор. В Python «джентльменское соглашение» легко нарушить случайно, и никто этого не заметит до появления бага. В Dart, если переменная объявлена как `final`, компилятор физически не даст её изменить — код просто не скомпилируется. Это делает код надежнее.

**4. Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.**
Позиционные параметры передаются строго в том порядке, в котором они объявлены в функции. Именованные параметры (в фигурных скобках) передаются по имени, и их порядок не важен. Слово `required` делает именованный параметр обязательным.
_Пример:_ `describePet(name: 'Барсик', age: 3);` (здесь мы явно указываем, какому параметру какое значение даем).
